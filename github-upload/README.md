# 기후위기의 사각지대
서울 폭염·침수 취약지역과 돌봄·대피시설의 공간적 불일치 (250m 격자)
스마트시티융합기술세미나(스마트도시데이터분석) 기말 프로젝트

**질문**: 재해 위험이 높고 취약한 사람이 많은 곳인데, 주변(3×3 격자, 약 750m)에 대응시설이 없는 곳은 어디인가?

| 단계 | 폭염 | 침수 |
|---|---|---|
| ① 위험 | Landsat 8/9 지표면온도 (GEE, 2026.06~08) 상위 20% | 2026 침수예상도 면적비율 상위 20% |
| ② 취약성 | 00시 65세 이상 생활인구 상위 20% | 지하층 주거(반지하) 세대 수 (구현 예정) |
| ③ 시설 | 무더위쉼터 3,936개 | 이재민임시주거시설 1,094개 |

## 현재 결과 (제안서 시점)
- 폭염: 고온 상위 20% 2,024칸 ∩ 고령 상위 20% → 649칸. 주변 3×3에 쉼터 없음 4칸, 누구나 이용 가능한 쉼터만 세면 87칸
- 침수: 침수 면적비율 상위 20% 665칸 중 주변 3×3에 임시주거시설 없음 225칸 (침수예상구역 밖 시설만: 319칸)

## 구성
- `site/` Cloudflare Pages에 올린 웹페이지 (Leaflet, 가공된 경량 GeoJSON만 포함)
- `gee/` Google Earth Engine 지표면온도 스크립트
- `analysis/` Python(geopandas) 전처리 코드
  - `01_flood_facilities.py` 침수예상도 정리, 격자 면적비율, 시설 3×3 집계
  - `02_lst_grid.py` GEE 결과(30m)를 250m 격자 중앙값으로 집계
  - `03_elderly_pop_shelter.py` 00시 65세 이상 생활인구, 고온·고령 교집합, 쉼터 3×3 집계

## 원자료 (용량·재배포 문제로 저장소에 포함하지 않음)
- 서울 열린데이터광장: 무더위쉼터(OA-21065), 이재민임시주거시설(OA-21064), 250m 격자 생활인구(OA-22784)
- 서울시 풍수해 침수예상도·침수흔적도, 국가 250m 격자(EPSG:5179), 건축물대장
- USGS Landsat 8/9 Collection 2 Level 2 (Google Earth Engine)

좌표계는 모두 EPSG:5179로 통일했다.
